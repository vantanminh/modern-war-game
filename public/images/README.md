# Image asset manifest

Put image files in the folders below with these exact names:

- `units/courier.webp`
- `units/vanguard.webp`
- `units/striker.webp`
- `units/ember.webp`
- `buildings/command-core.webp`
- `buildings/refinery.webp`
- `buildings/barracks.webp`
- `buildings/motor-pool.webp`
- `buildings/sentry.webp`
- `resources/resource-node.webp`

The game loads these files from `/images/...` and falls back to simple shapes if a file is still missing.
